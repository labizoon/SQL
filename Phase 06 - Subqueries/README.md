# SQL Subqueries

This folder contains examples of SQL subqueries, one of the most important SQL concepts used to write dynamic and powerful queries.

## Topics Covered

- Single Row Subqueries
- Multiple Row Subqueries
- IN Subqueries
- EXISTS Subqueries
- Correlated Subqueries
- Subqueries in FROM Clause
- Subqueries in SELECT Clause
- Practice Questions

## Learning Outcomes

After completing this folder, you will be able to:

- Write nested queries.
- Compare values using subqueries.
- Use IN, EXISTS, and NOT IN.
- Build correlated subqueries.
- Use subqueries inside SELECT and FROM.
- Solve real-world SQL problems using subqueries.
