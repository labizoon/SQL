# Phase 04 – GROUP BY & HAVING

## Overview

This phase introduces `GROUP BY` and `HAVING`, two essential SQL clauses used to summarize and analyze data. They allow you to group rows based on one or more columns and apply aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()` to each group.

## Topics Covered

* `GROUP BY`
* `HAVING`

## Files

| File           | Description                                              |
| -------------- | -------------------------------------------------------- |
| `GROUP BY.sql` | Learn how to group rows and calculate summary statistics |
| `HAVING.sql`   | Filter grouped results using aggregate conditions        |

## Learning Objectives

After completing this phase, you will be able to:

* Group records by one or more columns.
* Calculate summaries for each group.
* Use aggregate functions with grouped data.
* Filter grouped results using the `HAVING` clause.
* Build reports for business and data analysis scenarios.

## Example Concepts

* Number of employees in each department
* Average salary by department
* Total sales by product category
* Highest salary in each department
* Departments with more than five employees
* Customers who placed more than three orders

## Prerequisites

Before starting this phase, you should understand:

* `SELECT`
* `WHERE`
* `ORDER BY`
* SQL Aggregate Functions (`COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`)
