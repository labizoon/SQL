# Phase 03 – SQL Functions

## Overview

This phase covers the most commonly used SQL aggregate functions. These functions are used to perform calculations on multiple rows and return a single result, making them essential for data analysis and reporting.

## Topics Covered

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

## Files

| File          | Description                             |
| ------------- | --------------------------------------- |
| `COUNT.sql`   | Count rows and non-NULL values          |
| `SUM.sql`     | Calculate the total of numeric values   |
| `AVG.sql`     | Calculate the average of numeric values |
| `MIN_MAX.sql` | Find the minimum and maximum values     |

## Learning Objectives

After completing this phase, you will be able to:

* Count records in a table.
* Calculate totals using `SUM()`.
* Find average values using `AVG()`.
* Retrieve minimum and maximum values.
* Use aggregate functions in real-world reporting scenarios.

## Example Concepts

* Total number of employees
* Average employee salary
* Highest and lowest product price
* Total sales amount
* Number of orders placed

## Prerequisites

Before starting this phase, you should understand:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `LIMIT`
* `DISTINCT`
* Basic filtering techniques
