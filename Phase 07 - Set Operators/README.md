# Phase 07 - Set Operators

This phase covers SQL Set Operators, which are used to combine the results of multiple SELECT statements.

## Topics Covered

- UNION
- UNION ALL
- INTERSECT
- EXCEPT (MINUS in Oracle)
- Rules for Set Operators
- Practice Questions
- Solutions

## Learning Objectives

- Understand when to use each set operator.
- Learn the difference between UNION and UNION ALL.
- Find common records using INTERSECT.
- Find missing records using EXCEPT.
- Practice combining multiple queries.
