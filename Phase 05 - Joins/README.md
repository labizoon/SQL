# Phase 05 – Joins

## Overview

This phase covers SQL Joins, one of the most important concepts in relational databases. Joins allow you to combine data from multiple tables using related columns, making it possible to retrieve meaningful information stored across different tables.

## Topics Covered

* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* `CROSS JOIN`
* `SELF JOIN`

## Files

| File             | Description                                                                      |
| ---------------- | -------------------------------------------------------------------------------- |
| `INNER JOIN.sql` | Retrieve matching records from both tables                                       |
| `LEFT JOIN.sql`  | Return all records from the left table and matching records from the right table |
| `RIGHT JOIN.sql` | Return all records from the right table and matching records from the left table |
| `CROSS JOIN.sql` | Generate every possible combination of rows between two tables                   |
| `SELF JOIN.sql`  | Join a table with itself to compare related rows                                 |

## Learning Objectives

After completing this phase, you will be able to:

* Understand relationships between tables.
* Retrieve related data using different join types.
* Identify when to use each type of join.
* Combine multiple tables in a single query.
* Solve real-world business problems using joins.

## Example Concepts

* Employees and their departments
* Customers and their orders
* Orders and products
* Employees and their managers (Self Join)
* Product combinations (Cross Join)
* Students and their courses

## When to Use Each Join

| Join Type      | Purpose                                                                      |
| -------------- | ---------------------------------------------------------------------------- |
| **INNER JOIN** | Return only matching rows from both tables                                   |
| **LEFT JOIN**  | Return all rows from the left table, with matching rows from the right table |
| **RIGHT JOIN** | Return all rows from the right table, with matching rows from the left table |
| **CROSS JOIN** | Return every possible combination of rows from both tables                   |
| **SELF JOIN**  | Join a table to itself to retrieve related records                           |
